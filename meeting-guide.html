ミーティング管理を開く

ミーティングの進め方

報告した内容を共有し、必要な対策を実践して、定着するまで確認します。

まず「共有のみ」か「継続して取り組む」かを分けます。役割に応じて表示されるボタンが異なります。

確認したい操作を選んでください
  • 全体の流れ
  • 報告する
  • 振り分ける
  • お知らせを確認する
  • 取り組みを進める
  • 定着を確認する
  • 意見・提案
  • 後から見返す

掲載画面は操作説明用の架空データです。画像を押すと別タブで拡大できます。

全体の流れ

主任が報告を確認し、対応方法を選びます。

共有のみ → お知らせ

例：備品の保管場所の変更を周知する。

下書きを確認して登録 → スタッフが内容確認 → 全員確認後は履歴へ。

継続対応 → 取り組み

例：補充漏れを防ぐため、確認手順を改善する。

下書きを確認して登録 → 内容を理解 → 実践・振り返り → 院長が定着確認。

スタッフ：説明を受けて内容を理解し、日常業務で実践します。
主任：説明・確認状況・振り返りを取りまとめ、院長へ定着確認を依頼します。
院長：定着を確認し、完了または継続を判断します。

報告するスタッフ

1. ヒヤリハット・アクシデントを報告する

  1. 「ヒヤリハット・アクシデント報告」を開きます。
  2. 入力欄の質問に答え、「次へ」で進みます。修正するときは「戻る」を押します。
  3. 最後に内容を確認し、「報告を登録」を押します。

報告を登録しただけでは、お知らせや取り組みにはなりません。主任が内容を確認して振り分けます。

報告入力の画面を見る
主任

2. お知らせ・取り組みに振り分ける

  1. 報告を開き、内容を確認します。
  2. 「共有のみ → お知らせにする」または「継続対応 → 取り組みにする」を選びます。
  3. 報告の文章を引き継いだ下書きが開きます。共有する文章・対策・完了条件を確認し、必要に応じて直します。
  4. 「お知らせを登録」または「取り組みを登録」を押します。登録した案件がそのまま表示されます。

下書きが開いた段階では、まだ登録されていません。「キャンセル」で取り消せます。元の報告の画像は自動コピーされません。必要な画像は下書きで選んでください。

振り分けボタンと下書きの画面を見る
確認対象のスタッフ・主任

3. お知らせを確認する

  1. 「お知らせ」で本文と添付画像を確認します。
  2. 分からない点があれば確認し、「確認しました」を押します。
  3. 主任は、未確認・確認済みの状況を確認します。

確認対象者全員が確認すると、通常一覧から外れて「確認済みの履歴」に残ります。「確認済みの履歴を表示」を押すと見返せます。

全員確認後に履歴へ移るのは、お知らせだけです。取り組みは全員確認後も続きます。

確認済みの履歴の画面を見る
スタッフ全員・主任

4. 取り組みを実践し、毎回振り返る

ミーティング未共有→ 全員確認済み→ 取り組み中→ 院長の確認待ち→ 定着完了
  1. スタッフ全員：詳細と完了条件を確認し、説明を受けて理解したら「確認しました」を押します。欠席者には主任が後から説明し、確認状況もチェックします。
  2. 主任：全員の確認後、対策を入力し「対策を追加して開始」を押します。
  3. スタッフ全員：共有された対策を日々の業務で実践します。
  4. 毎回のミーティング：「できていること」「困っていること」「追加する対策」を確認します。主任が追加の対策を「対策を追加」から記録します。

「確認しました」は、内容を理解したという確認です。取り組みの完了を意味するものではありません。

取り組み中の画面を見る
主任・院長

5. 定着を確認する

  1. 主任が、その取り組みの「完了条件」を満たしていることを確認します。
  2. 主任が「院長へ定着確認を依頼」を押します。
  3. 院長が内容を確認し、定着していれば「定着完了にする」を押します。
  4. 継続が必要な場合は、院長が「定着確認依頼を却下」を押します。取り組み中に戻り、対策を見直します。

取り組みの進行状況は、元の報告にも表示されます。同じ進行状況を報告側へ入力し直す必要はありません。

院長の確認画面を見る
主任・院長

6. 院長への意見・提案

この項目は、主任と院長に表示されます。

  1. 主任が「院長へ伝えたい内容」と「背景／理由」を入力して登録します。
  2. 院長が内容を確認し、「承認」「不承認」「保留」などの判断と、必要な理由を入力して保存します。
  3. 主任が結果と理由を確認します。

今回の「お知らせ／取り組みへの振り分け」は報告から行う機能です。意見・提案から自動で振り分ける機能はありません。

意見・提案の画面を見る

7. 元の報告や過去の内容を見返す

  • お知らせ・取り組みの「元の報告を開く」から、きっかけになった報告へ戻れます。
  • 元の報告の「お知らせを開く」「取り組みを開く」から、関連する案件へ移動できます。
  • 振り分け済みの報告は、報告タブの「アーカイブを表示」からも確認できます。
  • 関連先を開く操作では、検索や絞り込みを解除して対象を表示します。
  • 「関連する内容を確認できません」と出た場合は主任に確認してください。

閲覧専用端末では内容の確認・移動ができますが、登録・更新や「確認しました」の操作はできません。

院内で確認した運用と、このポータルの操作に基づく説明です。
