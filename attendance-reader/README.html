RC-S300/P 勤怠カード読取ツール

百々さんまたは院長が、受付のWindows 11 PCでセットアップしてください。カードが対応するか、まず1枚で読取テストします。

準備

  1. Sony公式手順に従い、RC-S300/PとNFCポートソフトウェアをセットアップします。
  2. このフォルダを受付PCの固定場所へ保存します。
  3. Node.js LTSをインストールします。

インストール

  1. setup.ps1を右クリックし、PowerShellで実行します。
  2. Windowsへ再サインインします。
  3. 勤怠管理の「設定」で端末IDをreception-1にし、「読取ツール：接続中」を確認します。
  4. 管理者画面のカード登録で、スタッフとカードIDを紐づけます。

オフライン時

通信できない打刻はPC内の%LOCALAPPDATA%\KalmiaAttendanceReader\offline-queue.jsonへ保存され、復旧後に自動送信されます。ログは同じフォルダのreader.logに保存されます。
